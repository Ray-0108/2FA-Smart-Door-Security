# 雙因子驗證（2FA）智慧門禁與異常稽核系統
結合 Arduino UNO 與 Python 序列埠即時監控的實體門禁專題，具備 RFID + 4 位數 PIN 碼雙重驗證、10 秒輸入超時攔截，以及連續 3 次異常觸發 30 秒強制鎖定機制。

* **硬體核心**：Arduino UNO、RFID MFRC522、4x4 矩陣鍵盤、LCD1602 (I2C)、SG90 伺服馬達
* **實測展示影片**：https://www.youtube.com/watch?v=nJvs3k7VlsM
* **原始碼位置**：請點擊上方 `2FA-Smart-Door-Security` 資料夾檢視 `.ino` 與 `.py` 程式碼。
